Compiling BlueprintJS SCSS as part of the build process is not really reasonable any more,
dart-sass has issues and @import is use throughout instead of @use. Our variable overrides
are not applied, and workaround are required for the custom SCSS functions to work properly.

Workaround for now is a blueprint.css generated by blueprintjs project with custom colors applied.

The blueprint CSS file does include CSS variables but they are not used by the actual components,
they're designed as design tokens, so we're using them as such.

The custom build doesn't have matching design tokens, only SCSS variables so we're just adding some
scss variables in the main.scss file for those we actually use that are modified
